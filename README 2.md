# Ассистент учителя

Справочник по типовым незаконным требованиям к учителям в Казахстане:
поиск по ситуации, ссылка на норму закона, шаблон вежливого отказа
и анонимный счётчик «со мной это было».

## Структура проекта

```
api/index.py              — бэкенд FastAPI (точка входа для Vercel)
shared/violations_data.py — единый список всех типовых случаев (редактируйте только здесь)
public/index.html         — фронтенд, отдаётся Vercel как статика
db_setup.py                — ручной пересев/обновление базы (необязателен для обычного деплоя)
requirements.txt           — зависимости Python
```

## Почему Postgres, а не SQLite

Vercel-функции serverless: файловая система эфемерна и не общая между
экземплярами. Файл SQLite в таком окружении не гарантирует, что счётчик
случаев сохранится между запросами и деплоями. Поэтому база — Postgres
(подключается как "Vercel Postgres", под капотом это Neon), общая для
всех экземпляров функции.

## Деплой на Vercel

1. Запушьте репозиторий на GitHub.
2. На vercel.com → New Project → импортируйте репозиторий. Vercel сам
   найдёт `app` в `api/index.py` и развернёт его без дополнительной настройки.
3. В проекте на Vercel: **Storage → Marketplace Database Providers → Neon**
   (бесплатный тариф достаточен), подключите её к проекту. Vercel добавит
   переменную окружения `DATABASE_URL` автоматически.
4. Передеплойте проект (Deployments → Redeploy), чтобы функция увидела
   новую переменную окружения.
5. Откройте домен проекта — таблицы и все случаи создадутся автоматически
   при первом запросе.

## Локальная разработка

```bash
npm i -g vercel        # если ещё не установлен
vercel link             # привязать папку к проекту на Vercel
vercel env pull .env.local   # скачать DATABASE_URL и другие переменные
vercel dev              # поднимет фронтенд и api/ так же, как в проде
```

Откройте http://localhost:3000.

Без Vercel CLI (например, с локальным Postgres или той же Neon-базой):

```bash
pip install -r requirements.txt
export DATABASE_URL="postgres://...."   # из Vercel → Storage → ваша база → .env.local
uvicorn api.index:app --reload
```

Откройте http://localhost:8000/ — статика в `public/` в этом режиме не
раздаётся автоматически uvicorn'ом, откройте `public/index.html` вручную
или пропишите fetch на `http://localhost:8000/api` для локальных тестов.

## Обновление или сброс данных

Отредактируйте `shared/violations_data.py` и задеплойте — база обновится
сама при следующем холодном старте. Для немедленного обновления или сброса
счётчиков без ожидания:

```bash
export DATABASE_URL="postgres://...."
python db_setup.py
```

## Ограничения, которые стоит знать

- Тексты норм закона даны в пересказе, не дословной цитатой. Сверьте
  номера статей и формулировки с adilet.zan.kz перед тем, как показывать
  сервис учителям — это справочный инструмент, не юридическая консультация.
- Счётчик анонимный и ничем не защищён от накрутки, кроме одной метки в
  localStorage браузера (её легко обойти). Для публичного проекта этого
  достаточно как честного ориентира, но не как точной статистики.
